# Virtual Studio Events — website

Static site for virtualstudio.events. No build framework — plain HTML/CSS/JS generated by `build_pages.py`.

## Structure
- `build_pages.py` — page chrome + core pages (services, studios, work, about, contact); runs `content_hub.register()`; writes all pages and `sitemap.xml`; syncs nav/footer into the hand-built `index.html`.
- `content_hub.py` — knowledge hub engine: pillars, guide template (TOC, related, Article schema, breadcrumbs), event-type landing pages, resources hub, glossary, news, tools, templates.
- `content_*.py` — the content: guides per pillar (`prepro`, `infra`, `sets`, `live`, `platforms`, `analytics`), `events` (landing pages), `misc` (FAQs, glossary, news, tools/templates HTML).
- `assets/` — CSS, JS (`main.js` site behaviour, `tools.js` calculators), fonts (Milliard woff2), images.

## Editing
1. Edit content in the relevant `content_*.py` (or `build_pages.py` for core pages / `index.html` directly).
2. `python3 build_pages.py`
3. Bump `CSSV` in `build_pages.py` if CSS/JS changed.
4. Commit and push to `main` — GitHub Actions deploys to S3 + CloudFront and invalidates.

## Adding a news item
Append to `NEWS` in `content_misc.py` with `date`, `title`, `body` (HTML) and `src` (list of (title,url)). Rebuild.

## Adding a guide
Append a dict to the pillar's `GUIDES` list: `slug`, `pillar`, `title` (SEO), `desc`, `h1` (HTML with `<span class="em">`), `h1_plain`, `lede`, `related` (slugs), `body` (HTML with `<h2>` sections). Rebuild — it appears in the pillar, hub, sitemap and footer automatically.
